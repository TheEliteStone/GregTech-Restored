# GregTech-Restored

Bug reports and feedback for GregTech: Restored, a Minecraft 1.20.1 Forge modpack by TheEliteStone featuring GregTech progression, guided quests, automation, and exploration.

This repository is the pack's issue tracker. The public release is delayed, and there is no new date.

## How to submit a useful report

1. Search [existing issues](https://github.com/TheEliteStone/GregTech-Restored/issues?q=is%3Aissue), including closed ones. When you search, spell GregTech as one word.
2. Open a [new issue](https://github.com/TheEliteStone/GregTech-Restored/issues/new/choose) and pick the form that fits:
   - **Gameplay, quest, or recipe bug** for quests, recipes, progression, and other play problems.
   - **Crash or startup problem** when the client or a dedicated server fails to start or crashes.
3. Give the pack version, and say whether it happened on the client or a dedicated server.
4. Describe how to reproduce it, what you expected, and what happened instead.
5. Add a screenshot when it makes the problem clearer. For a crash, paste the crash report or the relevant part of `logs/latest.log` from the instance folder, or from the dedicated server folder.
6. Remove private information before you post: player names you do not want public, IP addresses, session tokens, and home-folder paths.
7. Do not upload mod jars, the pack archive, or a world save. A relevant excerpt is more useful than a full file.

The pack is Minecraft 1.20.1 on Forge. Feedback that is not a bug can be a blank issue.
